# 👗 Fashion Store (Shein-like Website)

This project is a **full-stack e-commerce web application** inspired by **Shein**, built with **React**, **JavaScript**, and **PostgreSQL**.  
The platform allows users to browse products, add items to cart, manage their accounts, and experience a modern online shopping interface.  

🎨 [View Design on Figma](https://www.figma.com/design/7ozVwYfLwcZPf5lUHFMvop/Untitled?node-id=1-2&p=f&t=zgiWriYOZf6lxvCE-0)  

---

## ✨ Features

- 🔎 **Search & filters** — easily find what you’re looking for  
- 🛒 **Shopping cart & checkout** — add/remove products, update quantities  
- 👤 **User accounts** — sign up, log in, and manage profile  
- 🎨 **Modern UI** — based on a custom Figma design  

---

## 🛠️ Tech Stack

- **Frontend:** React + JavaScript  
- **Backend:** Node.js / Express (API layer)  
- **Database:** PostgreSQL  
- **Design:** Figma  
- **Styling:** CSS
